Listmonk template variables

    
Every variable available inside your templates. Use these directly in HTML or in the builder's content blocks.

    

      
VariableDescription

      
        
{{ "{{" }} .Message {{ "}}" }}The campaign body content — this is where your email text goes. Required in every template.

        
{{ "{{" }} .Campaign.Name {{ "}}" }}The campaign name as set in listmonk

        
{{ "{{" }} .Campaign.Subject {{ "}}" }}The campaign subject line

        
{{ "{{" }} .Campaign.FromName {{ "}}" }}Sender name

        
{{ "{{" }} .Campaign.FromEmail {{ "}}" }}Sender email address

        
{{ "{{" }} .Subscriber.Email {{ "}}" }}Subscriber's email address

        
{{ "{{" }} .Subscriber.FirstName {{ "}}" }}Subscriber first name (if set)

        
{{ "{{" }} .Subscriber.LastName {{ "}}" }}Subscriber last name (if set)

        
{{ "{{" }} .Subscriber.Name {{ "}}" }}Full subscriber name

        
{{ "{{" }} .Subscriber.Attribs.field {{ "}}" }}Any custom subscriber attribute (replace "field" with your attribute name)

        
{{ "{{" }} UnsubscribeURL {{ "}}" }}One-click unsubscribe URL. Required for compliance.

        
{{ "{{" }} ManageSubscriptionURL {{ "}}" }}Link for subscribers to manage their preferences

        
{{ "{{" }} OptinURL {{ "}}" }}Double opt-in confirmation URL (use in opt-in confirmation templates)

        
{{ "{{" }} template "email-header" . {{ "}}" }}Required at the top of every template — loads listmonk's internal header

        
{{ "{{" }} template "email-footer" . {{ "}}" }}Required at the bottom of every template — loads listmonk's internal footer
