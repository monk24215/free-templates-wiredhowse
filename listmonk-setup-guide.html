Step 05 of 06
Key Variables In Your Template
{{ template "content" . }}
Required. Where your campaign body text injects. Must be in every template.
{{ "{{" }} UnsubscribeURL {{ "}}" }}
Required for compliance. One-click unsubscribe link.
{{ "{{" }} .Campaign.Subject {{ "}}" }}
The campaign subject line — useful for showing it inside the email.
{{ "{{" }} .Campaign.Name {{ "}}" }}
Your campaign name as set in listmonk. Good for headers.
{{ "{{" }} .Subscriber.FirstName {{ "}}" }}
Subscriber's first name for personalization. Falls back blank if not set.
{{ "{{" }} .Subscriber.Attribs.field {{ "}}" }}
Any custom subscriber attribute. Replace field with your attribute name.
Full variable reference at freetemplates.wiredhowse.app/#variables
